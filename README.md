Velvet Vault is a one-room stealth heist game: sneak past patrolling guards and sweeping security cameras, crack the glass case, steal the Star Sapphire, and slip out the south door before the alarm fills. Three gallery halls of rising difficulty, hand-drawn canvas art, keyboard or click-to-move controls, and no libraries — just plain JavaScript.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — move with WASD or arrow keys (Shift to sprint, which is loud), stand at the sapphire case to crack it, and reach the green EXIT door to escape.
